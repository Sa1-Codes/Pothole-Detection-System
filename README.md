# Pothole-Detection-System
This is pothole detection system using TinyML which can be be deploy on an edge device to do realtime processing.
System detects the pothole and inform the driver so that drivers can take the appropriate action how to avoid the pothole.
System also keep the record of the potholes detected along with its location in form on cordinate i.e longitude and latitude and stores the record on a remote database.
Authorities can access the database so that they can take appropriate action for the recovery of the pothole.
